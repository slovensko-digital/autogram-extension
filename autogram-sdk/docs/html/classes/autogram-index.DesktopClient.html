    Signs one or more documents. Multiple documents are signed together into a single ASiC_E container ("spoločná autorizácia dokumentov").

    Autogram >= 2.8.0 is used via POST /api/v1/sign. Older versions fall back to the legacy POST /sign endpoint, which supports one document only – signing multiple documents (or requesting v1-only checks) with an older Autogram emits the appVersionTooLow state and throws AutogramAppVersionTooLowException (code app-version-too-low).
